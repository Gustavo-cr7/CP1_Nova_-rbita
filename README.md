# CP1_Nova_Orbita

## Sistema de Seguranca Ambiental da Base Lunar

Projeto desenvolvido para o CP1 Mission Control

Tema Residencia e Base

## Objetivo

Desenvolver um sistema para analisar as condicoes ambientais da Base Lunar e auxiliar na seguranca dos astronautas

O sistema analisa dados como oxigenio CO2 temperatura pressao capacidade e ocupacao dos modulos

## Programa 1

O programa de monitoramento analisa os dados atuais da base

Ele calcula indicadores ambientais verifica a capacidade dos modulos e classifica a situacao como

NORMAL
ATENCAO
CRITICO

## Programa 2

O simulador permite testar a entrada de novos astronautas em um modulo

O usuario informa o modulo a quantidade de novos astronautas e a situacao da ventilacao

O sistema simula o impacto ambiental e apresenta uma recomendacao
